# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project focuses on analyzing e-commerce sales and customer data using **SQL and Power BI** to identify sales performance, customer behavior, and key business insights.

The project demonstrates practical skills in **data analysis, SQL querying, KPI development, and interactive dashboard creation**.

## 🛠️ Tools & Technologies

* **SQL / MySQL** – Data analysis and querying
* **Power BI** – Data visualization and dashboard development
* **Excel / CSV** – Dataset handling

## 🎯 Business Objectives

* Analyze overall sales performance
* Understand customer purchasing behavior
* Identify important sales and customer KPIs
* Analyze revenue and order-related metrics
* Present insights through an interactive Power BI dashboard

## 📊 Key KPIs

The Power BI dashboard includes key metrics such as:

* Total Revenue
* Total Orders
* Total Customers
* Average Order Value

## 🔍 Analysis Performed

### SQL Analysis

SQL queries were used to analyze the e-commerce data and extract meaningful business information.

The analysis includes:

* Revenue analysis
* Order analysis
* Customer analysis
* Aggregation and filtering
* Business-focused SQL queries

### Power BI Dashboard

The analyzed data was used to create an interactive Power BI dashboard containing KPI cards and visualizations for business analysis.
